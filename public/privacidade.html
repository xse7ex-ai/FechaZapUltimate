POLÍTICA DE PRIVACIDADE — CLOSI

Última atualização: Outubro de 2026 • Em conformidade com a WhatsApp Cloud API (Meta) e LGPD

1. QUEM SOMOS E ESCOPO DO SERVIÇO

O CLOSI é uma plataforma de gestão de orçamentos, CRM e comunicação com clientes para profissionais autônomos e empresas. Contato para suporte e privacidade: fechazap.suporte@gmail.com.

2. USO DA WHATSAPP CLOUD API (META) E CONSENTIMENTO

O CLOSI integra-se à WhatsApp Cloud API oficial da Meta Platforms, Inc. para viabilizar a comunicação direta entre prestadores de serviço e seus clientes finais:

  • Comunicação Solicitada: O aplicativo destina-se exclusivamente ao envio de orçamentos previamente solicitados pelo cliente e ao suporte ao cliente.
  • Consentimento Prévio Obrigatório: O usuário do CRM declara possuir consentimento prévio (opt-in) do cliente antes do cadastramento e envio de qualquer mensagem via WhatsApp.
  • Vedação de Disparo em Massa e Spam: É estritamente proibido o uso da plataforma para disparo em massa, spam, ou envio de mensagens não solicitadas.

3. DADOS COLETADOS E FINALIDADE RESTRITA

Coletamos dados exclusivamente para a geração, controle de orçamentos e atendimento ao cliente:

a) Dados do profissional usuário: Nome, e-mail, telefone comercial, dados da empresa (razão social, CNPJ, endereço) e chave PIX para inserção nas propostas.

b) Dados dos clientes finais: Nome e número de telefone celular fornecidos voluntariamente para elaboração e recebimento do orçamento.

c) Dados de propostas comerciais: Itens, valores e condições acordadas para a prestação do serviço.

d) Dados de pagamento (planos PRO/TURBO): Processados diretamente pela Stripe sob certificação PCI-DSS. O CLOSI não armazena dados de cartão de crédito.

4. NÃO VENDA DE DADOS PESSOAIS

O CLOSI NUNCA vende, comercializa, aluga ou compartilha dados pessoais de usuários ou de seus clientes para fins de publicidade, marketing de terceiros ou corretores de dados.

Os dados são compartilhados unicamente com os provedores de infraestrutura indispensáveis para o serviço:

  • Meta Platforms, Inc. (WhatsApp Cloud API para envio e recebimento de mensagens autorizadas);
  • Supabase Inc. (banco de dados em nuvem seguro e criptografado);
  • Stripe Inc. (processamento seguro de pagamentos e assinaturas);
  • Google Cloud (Gemini API para geração assistida de textos de propostas, no plano TURBO).

5. REVOGAÇÃO DO CONSENTIMENTO (OPT-OUT A QUALQUER MOMENTO)

O cliente final tem o direito garantido de revogar o opt-in e interromper o recebimento de mensagens a qualquer momento:

Basta responder à conversa no WhatsApp com as palavras PARAR, CANCELAR ou SAIR, ou solicitar a interrupção diretamente ao prestador ou pelo e-mail fechazap.suporte@gmail.com. O número é imediatamente bloqueado para novos envios automatizados.

6. SEUS DIREITOS PELA LGPD

Nos termos do art. 18 da Lei Geral de Proteção de Dados (LGPD), você pode a qualquer momento solicitar: confirmação de tratamento, acesso, correção, anonimização, portabilidade, eliminação e revogação do consentimento através do e-mail fechazap.suporte@gmail.com.

7. SEGURANÇA E RETENÇÃO

Mantemos seus dados apenas pelo período necessário para a prestação dos serviços ou cumprimento de obrigações legais. Adotamos isolamento estrito entre usuários (multi-tenant) e criptografia em trânsito e em repouso.

8. CONTATO

Canal de suporte e privacidade: fechazap.suporte@gmail.com
